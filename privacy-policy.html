English

Overview

Open multiple links later is a Chromium browser extension (Manifest V3) that works as a local batch URL management tool for cleaning, batch-opening, and copying a batch of URLs. This policy applies to versions distributed through the Google Chrome Web Store and the Microsoft Edge Add-ons store.

What we collect

We do not collect any personal data. This extension does not collect, store, transmit, share, or sell any user information, including browsing history, pasted text/URLs, device info, location, credentials, cookies/site data, or any analytics.

How data is processed

All processing happens entirely in your local browser. Cleaning, batch-opening, and removing duplicates run locally; copying tab URLs just copies the current window's tab addresses to your clipboard; settings, input, and task progress are stored locally (via chrome.storage) only to restore your preferences and show remaining counts, and never leave your device.

When we go online

Never. The extension contains no network-request logic, connects to no server, uploads nothing, and loads no remote code.

Permissions used

  • tabs — read tab URLs (to copy them) and create/close tabs.
  • storage — save settings, input, task progress, and full state locally.
  • alarms — schedule the next batch by the chosen interval and wake the task on time.
  • sidePanel — provide the persistent side panel UI.

No host permissions, no <all_urls>, no content-script injection, no history/cookies/webRequest.

Third parties

None. We do not use any third-party service, SDK, ad, or analytics tool.

Changes

If this policy changes, we update this page and the version number.

Contact

For privacy or compliance questions, contact the author via the contact info published on the Chrome Web Store or Microsoft Edge Add-ons listing.

中文

概述

Open multiple links later 是一款基于 Chromium 的浏览器扩展（Manifest V3），定位为本地运行的批量 URL 管理工具，用于「URL 提纯、批量打开、标签页 URL 管理」。本政策同时适用于通过 Google Chrome Web Store 与 Microsoft Edge 加载项商店 分发的版本。

我们收集什么？

我们不会收集任何个人数据。 本插件不采集、不存储、不传输、不共享、不出售任何用户信息，包括浏览历史、粘贴的文本/URL、设备信息、位置、账号凭据、Cookie/站点数据、任何统计或匿名分析。

数据如何被处理？

所有数据处理均完全在你的本地浏览器内完成。提纯、批量打开、去除重复项均在本机运行；复制标签页 URL 仅把当前窗口标签页地址复制到本机剪贴板；设置、输入与任务进度通过本地存储（chrome.storage）保存，仅用于恢复偏好与显示剩余计数，不离开你的设备。

何时会联网？

不会。 本插件不包含任何网络请求逻辑，不连接任何服务器，不上传任何内容，也不加载任何远程代码。

权限使用

  • tabs —— 读取当前窗口标签页 URL（用于复制），并创建/关闭标签页。
  • storage —— 在本机保存设置、输入、任务进度与完整状态。
  • alarms —— 按所选间隔安排下一次批量打开的定时唤醒。
  • sidePanel —— 提供常驻侧边栏界面。

无主机权限、无 <all_urls>、无内容脚本注入、无 history/cookies/webRequest。

第三方

无。我们不使用任何第三方服务、SDK、广告或分析工具。

变更

如本政策未来发生变化，会在本页面更新并同步插件版本号。
