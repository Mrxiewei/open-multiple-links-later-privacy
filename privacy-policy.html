Open multiple links later 隐私政策

Privacy Policy · 生效日期：2026 · 版本 v1.2.0

本政策同时适用于 Google Chrome 与 Microsoft Edge

概述

Open multiple links later 是一款基于 Chromium 的浏览器扩展（Manifest V3），定位为本地运行的 URL 管理工具，用于「URL 提纯、批量打开、标签页 URL 管理」。本政策同时适用于通过 Google Chrome Web Store 与 Microsoft Edge 加载项商店 分发的版本。

我们收集什么？

我们不会收集任何个人数据。

本插件不采集、不存储、不传输、不共享、不出售任何用户信息，包括但不限于：浏览历史、粘贴或输入的文本/URL、设备信息、位置、账号或凭据、Cookie 或站点数据、任何统计数据或匿名分析。

数据如何被处理？

本插件的所有数据处理均完全在您的本地浏览器内完成：提纯、批量打开、去除重复项均在本机运行；复制标签页 URL 只是把当前窗口标签页地址复制到您本机剪贴板；设置、输入与任务进度通过本地存储保存，仅用于恢复与显示剩余计数，不离开您的设备。

何时会联网？

不会。 本插件不包含任何网络请求逻辑，不连接任何服务器，不上传任何内容，也不加载任何远程代码。

权限使用

本插件仅申请实现功能所必需的最小权限：

  • tabs —— 读取当前窗口标签页 URL、创建/关闭标签页。
  • storage —— 在本机保存设置、输入、任务进度与完整状态。
  • alarms —— 按时间间隔安排下一次批量打开的定时唤醒。
  • sidePanel —— 提供常驻侧边栏界面。

这些权限均不涉及数据外传。

第三方

本插件不调用任何第三方服务、SDK、广告或分析工具。

变更

如本政策未来发生变化，会在本页面更新并同步插件版本号。

联系

如需就隐私或合规事宜联系作者，请通过 Google Chrome Web Store 或 Microsoft Edge 加载项商店 页面上公布的联系方式咨询。

Open multiple links later 尊重您的隐私。所有处理均在本地完成，零上传、零收集。
