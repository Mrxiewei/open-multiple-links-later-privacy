# Open multiple links later 隐私政策（Privacy Policy）

本仓库用于公开托管 **Open multiple links later** 浏览器扩展（Chromium，Manifest V3）的**隐私政策**。

本政策**同时适用于 Google Chrome 与 Microsoft Edge**，两个商店的「隐私政策 URL」使用**同一个地址**。

## 公开访问地址（Chrome 与 Edge 共用）

```
https://Mrxiewei.github.io/open-multiple-links-later-privacy/privacy-policy.html
```

> 该地址用于：
> - Google Chrome 网上应用店「隐私政策 URL」一栏；
> - Microsoft Edge 加载项商店「隐私政策 URL」一栏。

## 内容

- [`privacy-policy.html`](./privacy-policy.html) —— 面向用户的隐私政策页面（部署后由 GitHub Pages 发布）。

## 说明

Open multiple links later 全部功能与数据均在你本地浏览器运行，**不收集、不存储、不上传任何用户数据**，仅申请实现功能所必需的最小权限（`tabs`、`storage`、`alarms`、`sidePanel`），无远程代码。
